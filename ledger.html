Source tiers

Flags

WEAK_TIER
Sole source is T4/T5 (or T3/T4 with no primary) - cannot stand alone for a volume/adoption/performance figure
STALE
Older than staleness_cutoff, non-historical, non-evergreen - re-pull before external use
HISTORICAL
Old but stable fact - do not amber-flag
CURRENT
Evergreen statute/rate - never stale
CONFLICT
Another module gave a different number for the same quantity - see reconciliation
UNVERIFIED
T5-only, flagged in-text - source or remove before external use
DERIVED
Conversion or price-inflated valuation, not a mobilisable/measured base
VAGUE
Figure stated imprecisely by the source
DUP
Duplicate of another row
